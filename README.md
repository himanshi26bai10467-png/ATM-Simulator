# ATM Simulator 🏧

A simple ATM Simulator application created in Python using Jupyter Notebook for basic banking transactions.

## 🚀 Features
- **Account Selection:** Choose account type (Savings/Current).
- **Check Balance:** View current account balance.
- **Deposit Money:** Add funds to the account.
- **Withdraw Money:** Cash withdrawal with balance validation.

## 🛠️ How to Run
1. Clone this repository or download `ATM Simulator.ipynb`.
2. Launch Jupyter Notebook or JupyterLab:
   ```bash
   jupyter notebook
